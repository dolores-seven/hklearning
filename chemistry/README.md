# DSE 化学全景知识图谱

基于 DSE Chemistry 2022 新大纲（C&A Guide）+ 历年真题的**可交互知识图谱**。让一个没学过 DSE 化学的学生打开就能看到全科地图：12 必修单元 + 3 选修（选 2）+ 实验技能。

## 怎么打开

**直接双击** `dse-chemistry-map.html`（Chrome/Edge），无需联网、无需起服务器。

## 数据规模

| 维度 | 数量 |
|------|------|
| 课题节点 | 16（必修 12 + 选修 3 + SBA 1） |
| 公式叶 | 156（概念/方程式/反应/定律原理/实验） |
| 关系边 | 40（前置 15 + 组合出题 22 + 相关 3） |
| 母题 | 23（全覆盖 + 69 道变式题） |

## 图谱特色（化学定制）

- **知识类型 5 种**：概念(蓝) / 方程式(绿) / 反应(橙) / 定律原理(紫) / 实验(青)
- **范畴 9 组**：物质与结构 / 无机转化 / 反应与能量 / 碳化学 / 化学规律 / 工业 / 材料 / 分析 / 实验
- **2022 新大纲合规**：平衡移动用「Q vs Kc」解释，不采用已淘汰的勒沙特列原理
- **实验覆盖**：SBA 独立分支（安全/仪器/变量控制/数据分析/误差）+ 每课题标注常考实验
- **providedInfo 标注**：考场提供的资料（周期表/电极电位表）已标注，区分「要背」vs「考场有得查」
- **伪立体四机制**：分层下钻 / 边类型开关 / 焦点辐射 / 新手模式

## 考试结构依据

- 卷一：必修 60%（甲部 MC + 乙部 LQ）
- 卷二：选修 20%（工业/材料/分析 3 选 2，~97% 考生选工业+分析）
- SBA：20%（≥1 次容量分析 + ≥1 次定性实验）
