## 通用生成参数

### 推荐参数设置
```
--ar 16:9           # 横向布局,适合PPT和报告
--quality 2k        # 高质量,适合打印和演示
--style educational # 教育风格
```

### 色彩方案建议
- 黑板风格:黑色背景+彩色粉笔元素
- 主色:红色(警告/重点)、蓝色(信息)、绿色(正确/建议)
- 辅助色:黄色(提示)、灰色(次要信息)
- 对比色:用于突出数据差异(达标vs未达标、优势vs劣势)

### 字体要求
- 标题:粗体大字,醒目清晰
- 正文:易读性优先,字号适中
- 数据:数字突出显示,使用大号字体
- 结论:使用边框或背景色强调

### 布局要求
- 信息层次清晰,主次分明
- 适当留白,避免拥挤
- 使用视觉引导线(箭头、路径、连接线)
- 保持视觉平衡和对称性

## 使用建议

### 图像生成工具选择
1. **Midjourney**:适合创意风格,使用v1简洁版prompt
2. **DALL-E 3**:适合精确文字和数据,使用v2详细版prompt
3. **Stable Diffusion**:适合定制风格,需要调整prompt格式
4. **Google Imagen**:适合教育主题,推荐使用
5. **Adobe Firefly**:适合商业用途,版权安全

### 生成后处理
1. 检查文字清晰度和准确性
2. 验证数据标注是否正确
3. 确认颜色对比度是否足够
4. 测试在不同背景下的显示效果
5. 必要时使用图像编辑软件微调

### 批量生成建议
如果需要批量生成所有6个图表:
1. 按顺序逐个生成,确保质量
2. 保持风格一致性(相同的风格参数)
3. 保存原始prompt便于后续修改
4. 建立版本管理系统(v1, v2, v3...)
