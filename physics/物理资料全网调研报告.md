# DSE 物理资料全网调研报告

> 调研日期：2026-08-20
> 目的：核实「物理的 DSE 资料是否不如数学多」，盘点物理可用数据源，为物理图谱深化提供弹药

---

## 一、结论摘要

**「物理资料不如数学多」这个印象，部分正确、部分不成立。**

- **正确的地方**：物理缺少数学那种**「课题 → 年份 → 题号」的一目了然网页索引**（数学有 MathsKiller 的 2012-2024 完整题号表，物理没有对等免费资源）。搜索引擎里搜「物理 by topic 题号」出来的结果远比数学少、且分散。
- **不成立的地方**：物理的 **by-topic 真题 PDF 覆盖比数学更完整**（dsetreasure 把五大必修 + 四个选修全部按 LQ/MC 分类好，还带 2012-2025 逐步题解），并且物理还多出 HKCEE(1990-2011) + HKALE(1980-2013) 两套历史题库。此外物理有数学没有的**量化分值数据**（每个课题在卷一占多少分）。

一句话：**物理不是资料少，是「索引化程度」低**——数据是有的，散落在多个站点，缺一个把题号结构化提取出来的动作。

## 三、数学 vs 物理资料对比

| 维度 | 数学（核心 + M2） | 物理 | 谁更全 |
|------|------------------|------|--------|
| **「课题→题号」网页索引** | ✅ MathsKiller 完整表（2012-2024） | ❌ 无对等免费资源 | **数学** |
| **By-topic 真题 PDF** | 部分（dse247 子页 404） | ✅ 五大必修 + 四选修全部 LQ/MC 分好 | **物理** |
| **逐步题解** | 无免费完整版 | ✅ 2012-2025 P1A/P1B/P2 全套 | **物理** |
| **量化分值/频率** | 频率 0-13（定性为主） | ✅ 每个课题具体分值范围 + 难度评级 | **物理** |
| **历史题库** | HKCEE 1980-2011 | HKCEE 1990-2011 + HKALE 1980-2013 | **物理** |
| **双语资料** | 中英 | 中英（by-topic 双语版） | 持平 |
| **官方题库** | OQB/DFS（学校订阅，仅 MC） | 无公开对等物 | **数学**（但都用不上） |

**核心差异**：数学赢在「**索引**」——有一个网站把 13 年题号清清楚楚列成表；物理赢在「**存量**」——真题 PDF 和历史题库更全，但**没有人把它做成题号索引**。这正好是我们的机会：物理图谱可以补上这个空白。

## 四、「物理资料不如数学多」的真相

1. **不是资料少，是索引化程度低**。物理 by-topic 真题、题解、历史卷其实比数学更齐全，但分散在 dsetreasure / dselink / dse247 / AfterSchool 多个站点，没有一个像 MathsKiller 那样把「课题 → 每年题号」摊开成表的页面。
2. **中文关键词搜索体验差**。搜「数学 by topic」直接出 MathsKiller；搜「物理 by topic」出来一堆补习社软文和 PDF 下载页，没有一个「题号索引」形态的结果。
3. **物理的「含金量信息」藏在文字里**。hktutorlink 那种课题分值、出题模式分析是纯文字网页，容易被搜索引擎降权，但对我们价值极高。

## 五、行动方案：怎么用这些资料补强物理图谱

### 建议 1：给课题节点补「量化分值」（最高优先，来自 hktutorlink）
把 hktutorlink 给出的分值范围写入课题节点的 `examWeight`（结构化数据）：
- 熱和氣體：12-18 分 / 電和磁：22-30 分 / 力和運動：25-35 分 / 波動：18-25 分 / 放射：8-14 分
- 难度评级（1-5）→ 对应 `diff` 字段
- 乙部三种出题模式 → 可写入母题的 `questionType` 标签体系

### 建议 2：用 dsetreasure 的 by-topic 结构校准叶子覆盖
dsetreasure 的子课题划分（如 1.1 Temperature/heat/internal energy、1.2 Transfer processes、1.3 Change of state）是官方 C&A Guide 的细分。逐课题对照我们的叶子，找出「官方有子课题但我们没叶子」的缺口。

### 建议 3：母题 appearances 题号化（需人工/半自动）
dse247 的 13 个力学 PDF + dsetreasure 的完整 PDF 是扫描版还是文字层待验证（数学的经验是 dse.life 的全是扫描版）。如果 PDF 有文字层 → 写脚本提取题号；如果无 → 维持现状，用「分值 + 频率」承担重要性角色。

### 建议 4：AL 28 细分 topic 做「跨课题组合」参考
dselink 的 AL 28 细分（Kinematics / Projectile / Newtonian / Momentum / Circular / Gravitation / E-field / Current Electricity / Magnetic / EMI / AC / Gases ...）直接对应卷一乙部的大题组合方式，可用来补 cotested 边。
